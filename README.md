# K地圖

邊玩邊熟悉地圖的網頁遊戲。把每一塊地方從灰色點亮成全彩，集滿印章。介面與知識卡有中文、英文、日文三種語言。

網頁版：<https://agan0617.github.io/KMap/>　Android 版：[KMapApp](https://github.com/agan0617/KMapApp)（WebView 外殼，網頁更新 App 就跟著更新）

## 地區

| 地區 | 單位 | 分區（首頁可選範圍） | 印章 |
|---|---|---|---|
| 日本 | 47 都道府縣 | 北海道、東北、關東、中部、近畿、中國地方、四國、九州・沖繩 | 圓形御朱印 |
| 中國 | 31 個省級行政區＋港澳（33） | 華北、東北、華東、華中、華南、西南、西北 | 方形印章 |
| 世界 | 197 國 | 亞洲、歐洲、非洲、北美洲、南美洲、大洋洲 | 護照入境章 |

- **世界的 197 國**：聯合國 193 個會員國，加上臺灣、梵蒂岡、科索沃、巴勒斯坦。港澳算在中國內。格陵蘭、西撒哈拉、各國海外屬地畫成灰色底圖，不能點
- **選了分區**：出題、限時連擊、鄰接旅行只用那一區，地圖放大到那一區，區外變淡。今日挑戰不受影響，一律整個地區
- **太小點不到的地方**（梵蒂岡、摩納哥、澳門…）會多畫一個固定大小的圓點

## 玩法

- **圖鑑**：點地圖上任一塊看知識卡，內容有首府、舊國名或簡稱、名產、名勝、小知識、方言。世界區的卡片附國旗。地名依縮放程度顯示，塞得下字才出現
- **找位置**：「秋田縣在哪？」在地圖上點出來
- **知識找地點**：看名產、名勝、首府、小知識或方言，猜是哪裡。提示裡的地名會遮成○○；兩個地方寫成一樣的名產名勝不出題
- **鄰接旅行**：陪 Komugi 從起點走到目的地，每一步只能走到相鄰的地方。虛線是橋、隧道或航線；步數等於最短路線拿三顆星
- **限時連擊**：60 秒內混合出題，每連對 5 題，每題多 1 分
- **今日挑戰**：每天一組固定的 10 題，只記第一次的成績，另計連續天數

### 熟練度

| 等級 | 條件 | 地圖顏色 |
|---|---|---|
| 未踏 | — | 灰 |
| 到訪 | 答對一次 | 淡 |
| 熟悉 | 第一次答對後隔 2 天以上又答對 | 中 |
| 制霸 | 熟悉，且「找位置」與「知識找地點」都答對過 | 全彩，蓋一個章 |

出題會優先挑到期該複習的、常錯的、還沒碰過的地方（Leitner 間隔複習）。進度存在瀏覽器的 localStorage，各地區分開記。

### 雲端存檔

設定裡可以連上 CloudSave（私有 repo），進度會同步到 `saves/kmap.json`，手機、電腦、App 共用：

- **token**：存在各裝置，瀏覽器直接呼叫 GitHub API，沒有中間伺服器。要能讀寫 CloudSave 的 Contents
- **沿用連線**：K地圖跟 K書吧、魔塔在同一個網域，這台瀏覽器連過它們就直接沿用那組 token。App 的 WebView 資料分開，要在 App 裡另外貼一次
- **合併**：熟練度、答對次數取高的；複習排程用最近玩的那一份；最佳分數取高的；今日挑戰同一天兩邊都有就留本機的。多台裝置同時玩不會互相蓋掉
- **同步時機**：打開時、切回畫面時拉一次；答題後 3 秒推上去；切走畫面前把還沒推的推上去
- **不同步的**：語言、音樂、音效這類設定，各裝置自己記

### 語言

首頁右上角切換中文（繁體）、英文、日文，介面和知識卡都會換，選擇記在瀏覽器裡。第一次打開時依瀏覽器語言決定。名字下面的小字：

| 地區 | 中文 | 英文 | 日文 |
|---|---|---|---|
| 日本 | 假名讀音 | 日文漢字 | 假名讀音 |
| 中國 | 漢語拼音 | 中文 | 假名讀音 |
| 世界 | 英文國名 | 當地語言的國名 | 英文國名 |

### 音樂與音效

全部用 Web Audio 即時合成，沒有音檔。背景音樂依地區換音階：日本是都節音階的撥弦聲、中國是五聲音階、世界是大調；限時連擊時換成快板。設定裡可以分開關掉音樂和音效。

## 檔案

| 路徑 | 內容 |
|---|---|
| `data/<地區>-map.js` | 地圖的 SVG 路徑、相鄰關係、跨海連結、插圖框、底圖、各洲取景框。由 `tools/build-map.mjs` 產生，不要手改 |
| `data/japan-info.js` | 日本知識卡的中文底稿 |
| `data/japan-info.en.js`、`.ja.js` | 日本知識卡的英文、日文翻譯，陣列與底稿逐項對應；缺的欄位顯示中文 |
| `data/china-info.js`、`world-info.js` | 中國、世界的分區、欄位名稱、印章樣式 |
| `data/china-units-*.js`、`world-units-*.js` | 中國各省、世界各國的知識卡，每一區直接寫中英日三份 |
| `js/i18n.js` | 介面文字（中英日） |
| `js/regions.js` | 地區清單，把地圖和知識卡組成一個地區，依語言給地名與卡片內容（日本與中國、世界兩種資料格式各有一套） |
| `js/store.js` | 存檔、熟練度、間隔複習、兩份進度的合併 |
| `js/sync.js` | 雲端存檔（CloudSave） |
| `js/quiz.js` | 出題、鄰接旅行的路線計算 |
| `js/map.js` | SVG 地圖：縮放、拖曳、點擊、標籤、小國圓點、Komugi |
| `js/audio.js` | 音樂與音效 |
| `js/main.js` | 畫面與玩法流程 |
| `js/version.js` | 版號 |

沒有建置步驟，`index.html` 直接載入所有檔案。

## 重產地圖與圖示

```
npm install
node tools/build-map.mjs japan
node tools/build-map.mjs china
node tools/build-map.mjs world
powershell -File tools\build-icons.ps1 [-AndroidRes <KMapApp\app\src\main\res>]
```

- **地圖**：第一次會下載 Natural Earth 的原始檔到 `tools/.cache/`：日本、中國用 1:10m 省縣界（約 40MB），世界用 1:50m 國界（約 3MB）。用 mapshaper 簡化並保留拓撲，再用 topojson 算相鄰關係。日本、中國用等距圓柱投影，世界用 Equal Earth 等面積投影（中央經線 11°E）。哪些算國家、哪些併進別國或畫成底圖、資料不準的相鄰關係、跨海連結、插圖框、各洲取景框，都寫在 `build-map.mjs` 的設定裡
- **圖示**：用 Edge headless 截 `tools/icon.html`

版號只寫在 `js/version.js`：首頁標題旁顯示它，`sw.js` 也拿它當快取名稱。改了網頁就要加版號，舊快取才會被換掉。

## 資料來源

- 地圖：[Natural Earth](https://www.naturalearthdata.com/)，公有領域
- 知識卡：依維基百科整理，每張卡附連結（日本依日文維基；中文、英文介面分別連到該語言的維基）
