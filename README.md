# K地圖

邊玩邊熟悉地圖的網頁遊戲。把每一塊地方從灰色點亮成全彩，集滿印章。介面與知識卡有中文、英文、日文三種語言。

網頁版：<https://agan0617.github.io/KMap/>　Android 版：[KMapApp](https://github.com/agan0617/KMapApp)（WebView 外殼，網頁更新 App 就跟著更新）

## 地區

九個分頁，依序是臺灣、日本、中國，以及世界的六大洲（亞洲、歐洲、非洲、北美、南美、大洋洲），分頁放不下時可以左右滑。第一次打開預設臺灣。

- **各洲分頁**：共用同一張世界地圖，只看那一洲的範圍，其他洲的國家畫成不能點的底圖；跨洲的連結（白令海峽等）在洲內不算相鄰。每一洲各有自己的關卡與護照章冊；熟練度記在同一份世界進度裡，所以拆洲以前答過的都還在。成就照世界整體算（例如世界 50 章），門檻跟以前一樣。分區照聯合國地理分區，臺灣慣用叫法優先（伊朗放西亞、英國與愛爾蘭放西歐、德奧瑞放中歐），寫在 `data/world-continents.js`
- **選了分區**：首頁與圖鑑的地圖放大到那一區，區外變淡，兩邊共用同一個設定；挑戰模式只出那一區。關卡模式不受影響，一律整個地區出題
- **臺灣**：金門、馬祖放在左上的插圖框。卡片的「舊稱」欄放打狗、諸羅、竹塹這類舊地名；直轄市與市不列縣政府所在地
- **太小點不到的地方**（梵蒂岡、摩納哥、澳門…）會多畫一個固定大小的圓點

## 玩法

- **圖鑑**：點地圖上任一塊看知識卡，內容有首府、舊國名或簡稱、名產、名勝、小知識、方言。各洲的卡片附國旗。卡片底下有上一個／下一個（順序同紀念章冊，電腦可用左右方向鍵），不用關掉就能一路看下去；視窗大小固定、內容在中間捲，切換時按鈕位置不變。地名依縮放程度顯示，塞得下字才出現
- **題目**：關卡裡三種題目混著出（找位置 25%、知識題 40%、選擇題 35%）——
  - **找位置**：「秋田縣在哪？」在地圖上點出來
  - **知識題**：看提示猜是哪裡，在地圖上點出來。一半題目用知識卡（名產、名勝、首府、小知識、方言，以及每地 8 條的「更多知識」：名人、運動、作品舞台、祭典、地名由來、代表動植物、之最、冷知識；提示裡的地名會遮成○○，兩個地方寫成一樣的名產名勝不出題，遮掉後剩不到 3 個字的（「宜蘭餅」→「○○餅」）也不出；選擇題、是非題、連連看的選項不用名字裡就有地名的名產名勝），另一半用地圖本身出：鄰居（「和 A、B、C 都相鄰」，沒有別的地方也同時和它們相鄰才出）、方位（「X 的東邊鄰居」，X 在那個方向只有一個鄰居才出）、國旗（只有六大洲）、外語名（用另一種語言的名稱找位置；日文漢字跟中文只差新舊字體的不出）、交通（「從 A 經由〈青函隧道〉可以到哪裡？」）、猜猜我是誰（三條不同類的提示一條一條亮，每少看一條 +2 幣）、排行（「臺灣人口第 2 多的是哪裡？」，只問前三名與最後兩名、跟前後名次差 3% 以上；面積、人口、人口密度）、之最（極點、最大的湖、最高峰所在…，答案在那一頁唯一，有主權爭議或跨界的不收）
  - **選擇題**：四選一，按按鈕作答（點地圖不算）：地圖上亮一塊選名字、首府／首都、名產、名勝、鄰居、比方位（四個裡哪個最北／南／東／西，第一名要明顯勝出才出）、看國旗選名字、比一比（兩個地方誰面積大／人口多、四個裡哪個最大，差距太小不出）、是非題（「〇〇是 X 的名產？」一半是真的、一半換成同一分區別的地方的）、連連看（四個地方配四個名產或名勝，中間沒配錯才算答對）。干擾選項先從同一分區挑、再挑鄰居；選擇題算「知識」類。插圖框裡的地方（沖繩、金門、馬祖）位置不是真實方位，方位類題目不用它們
- **分享成績**：關卡結算有「分享成績」按鈕，產生關數、過關與否、🟩🟥 對錯方格、已連續幾天完成今日挑戰；手機叫出系統分享選單（可貼 LINE），沒有就複製到剪貼簿
- **今日挑戰**：併在關卡模式裡。每天第一次過關（任何分頁、任何一關）就算完成今日挑戰：基本 +30、全對再 +30、連續天數每天再 +5（最多 +50）。首頁關卡模式的卡片寫今天完成了沒、已經連續幾天完成；結算畫面也會寫「已連續 N 天」。連續天數也把改版前各地區今日挑戰的紀錄算進去
- **關卡模式**：每個分頁一條無限往下的關卡，沒有星星，只分過關與否；過了才開下一關，沒過就再打一次。題目從整個地區隨機抽，用分頁＋關號當種子，所以同一關重打是同一組題
  - **過關門檻**：10 題要答對 5 題，每 10 關多要求 1 題（第 10 關 6 題、第 20 關 7 題…），第 40 關起封頂 9 題（不要求全對）
  - **限時關**：每 5 關一個，60 秒內要答對的題數＝那一關的門檻 + 2；限時關不顯示解析、答完自動跳
- **挑戰模式**：關卡模式下面那張綠色卡。只出找位置，照首頁選的分區出（照複習優先度、不連續出同一個地方），錯 3 次結束；各分頁各分區分開記最佳題數。答對一樣給幣、升熟練度

出題類的模式答完一題後，面板分成兩欄，題目旁邊顯示答案解析：答案在哪一區、和誰相鄰；答錯時你點的地方在答案的哪個方向、兩地相鄰還是中間隔了幾個；知識題的提示原本屬於誰；找位置題附首府與小知識。「看知識卡」「下一題」在地圖右下角；點畫面任何地方也是下一題。

### 熟練度

| 等級 | 條件 | 地圖顏色 |
|---|---|---|
| 未踏 | — | 灰 |
| 到訪 | 答對一次 | 淡 |
| 熟悉 | 第一次答對後隔 2 天以上又答對 | 中 |
| 制霸 | 熟悉，且「找位置」與「知識題」都答對過 | 全彩，蓋一個章 |

出題會優先挑到期該複習的、常錯的、還沒碰過的地方（Leitner 間隔複習）。作答中的地圖不顯示熟練度顏色，只標當題的對錯；首頁和圖鑑才看得到顏色。進度存在瀏覽器的 localStorage，各地區分開記。

### Komugi 與獎勵

Komugi 是戴耳機的柴犬，K地圖的吉祥物。首頁由上而下是：

1. **Komugi 小屋**：全身的 Komugi、稱號、下一個旅程稱號還差幾次升級、全地圖熟練度、肉球幣、衣櫃、扭蛋和紀念章冊按鈕
2. **關卡模式**（下一關、已過幾關；右半邊是今日挑戰完成了沒，連續天數做成黃色標籤；過關條件寫在遊玩畫面的標題下面）和**挑戰模式**（目前的分區；右半邊是「最佳紀錄：N 題！」標籤，沒玩過不顯示）
3. 地區分頁、分區、**地圖**：不能平移縮放（頁面下滑才不會誤觸），點一塊直接看知識卡；右上角是圖鑑按鈕；到訪過的地方標上地名（塞得下才顯示）
4. 熟練度進度條：四色分段（制霸、熟悉、到訪、未踏各幾個），右邊是「臺灣熟練度 33%」。熟練度＝到訪 1、熟悉 2、制霸 3 點的加總佔滿分的比例，跟小屋的全地圖熟練度、旅程稱號同一種算法

- **配件**：134 件，分 10 個部位（頭、眼睛、臉、脖子、衣服、背後、手上、腳、夥伴、背景），稀有度 N／R／SR／SSR。同一部位穿一件；拿到新配件時那個部位空著就自動穿上。首頁、衣櫃是全身，標題列、結算畫面是頭像（頭像戴得上頭、眼睛、臉、脖子四個部位）。「夥伴」是坐在 Komugi 旁邊的小動物
- **肉球幣 🐾**：答對 +1、到訪 +2、熟悉 +3、蓋章 +10、猜猜我是誰每少看一條提示 +1、關卡第一次過關 +10、今日挑戰（每天第一次過關）+30（全對再 +20，連續天數每天再 +5、最多 +30）、成就 +50。1.18.0 為了讓扭蛋有稀缺感重新平衡過（模擬每天 8 關、答對率 8 成：舊規則每關約 42 幣、約第 150 關就集滿；新規則每關約 27 幣，第 100 關約 23 件、第 400 關約 64 件、第 800 關約 105 件）
- **扭蛋**：100 幣一次，134 件配件全部在池子裡。每扭固定 40% 出新配件、60% 出已經有的（退 20 幣）；全部收集完以後都是重複的。新配件照稀有度 N 55%・R 30%・SR 12%・SSR 3% 挑，已經湊了幾件的套裝優先補（權重 ×3）。這樣設計是為了讓新配件平均分配在整個進程：純隨機會越齊越難抽到新的，模擬下來前 50 關拿 30 件、第 351～400 關只剩 5 件；固定出新率則新配件的節奏不會越後面越慢。夠扭兩次以上會多一顆「全部扭」：把肉球幣扭到不夠為止，一次列出拿到的所有配件。小屋的扭蛋按鈕平常跟衣櫃、紀念章冊同色，夠扭時才變紅並標出能扭幾次
- **成就**：32 個，各送 30 幣（不送配件）。其中 16 個是地區成就：臺灣、日本、中國、世界各四階（蓋幾個章、全制霸）
- **旅程稱號**：1000 個，綁全地圖熟練度。熟練度點數＝臺灣、日本、中國、世界所有地方的熟練度加總（到訪 1、熟悉 2、制霸 3，全部制霸 897 點），每到 0.1% 拿一個，所以每升級一個地方大約就多一個稱號。名字是 50 個形容 × 20 個階級（迷路的散步柴…最強的地圖之神），每 50 個換一個階級。首頁顯示最新拿到的那個，衣櫃裡可以改選任何一個拿過的
- **套裝與稱號**：25 套（臺灣之旅、日本祭典、太空任務、魔法師、海盜船、忍者、逛夜市、熊貓之家…），集滿可以一鍵穿上整套、設成首頁的稱號
- **衣櫃**：上面是全身預覽，下面依部位分頁，最後兩頁是稱號（旅程稱號＋套裝）與成就（進度幾分之幾、達成日期）。視窗固定高度，切分頁不會跳

成就、配件、套裝、旅程稱號、扭蛋規則定義在 `js/rewards.js`，配件圖案在 `js/komugi.js`，名稱與說明在 `js/i18n-rewards.js`。

### 雲端存檔

設定裡可以連上 CloudSave（私有 repo），進度會同步到 `saves/kmap.json`，手機、電腦、App 共用：

- **token**：存在各裝置，瀏覽器直接呼叫 GitHub API，沒有中間伺服器。要能讀寫 CloudSave 的 Contents
- **沿用連線**：K地圖跟 K書吧、魔塔在同一個網域，這台瀏覽器連過它們就直接沿用那組 token。App 的 WebView 資料分開，要在 App 裡另外貼一次
- **合併**：熟練度、答對次數取高的；複習排程用最近玩的那一份；最佳分數、統計取高的；成就與配件聯集；肉球幣與扭蛋次數每台裝置各記收支、合併時各裝置取大的再加總；Komugi 的裝扮與稱號用最近換的那一份；今日挑戰完成的日期聯集；過了的關聯集。多台裝置同時玩不會互相蓋掉
- **同步時機**：打開時、切回畫面時拉一次；答題後 3 秒推上去；切走畫面前把還沒推的推上去
- **不同步的**：語言、音樂、音效、底色這類設定，各裝置自己記

### 語言

首頁右上角切換中文（繁體）、英文、日文，介面和知識卡都會換，選擇記在瀏覽器裡。第一次打開時依瀏覽器語言決定。名字下面的小字：

| 地區 | 中文 | 英文 | 日文 |
|---|---|---|---|
| 臺灣 | 官方英文名 | 中文 | 日文常用讀音 |
| 日本 | 假名讀音 | 日文漢字 | 假名讀音 |
| 中國 | 漢語拼音 | 中文 | 假名讀音 |
| 世界 | 英文國名 | 當地語言的國名 | 英文國名 |

### 音樂與音效

全部用 Web Audio 即時合成，沒有音檔。背景音樂依地區換音階：日本是都節音階的撥弦聲、臺灣是羽調五聲音階、中國是宮調五聲音階、六大洲是大調；限時關換成快板。設定裡可以分開關掉音樂和音效。

### 底色

設定裡可以換整個 App 的底色（同 K書吧）：米（預設）、白、綠、夜，或「系統」跟著裝置的深色模式在米與夜之間切。地圖的熟練度顏色會從該底色的陸地色往分區色混，所以每種底色都看得出深淺。

## 檔案

| 路徑 | 內容 |
|---|---|
| `data/<地區>-map.js` | 地圖的 SVG 路徑、相鄰關係、跨海連結、插圖框、底圖、各洲取景框。由 `tools/build-map.mjs` 產生，不要手改 |
| `data/japan-info.js` | 日本知識卡的中文底稿 |
| `data/japan-info.en.js`、`.ja.js` | 日本知識卡的英文、日文翻譯，陣列與底稿逐項對應；缺的欄位顯示中文 |
| `data/taiwan-info.js`、`china-info.js`、`world-info.js` | 臺灣、中國、世界的分區、欄位名稱、印章樣式 |
| `data/world-continents.js` | 六大洲分頁：每一洲底下的地理分區與各分區的國家 |
| `data/stats.js` | 各地方的面積、人口（排行題）與「之最」題；來源寫在檔頭 |
| `data/extra-<地區>.js` | 知識卡的「更多知識」（臺灣、日本、中國、世界各一檔，三語）。subagent 寫、附來源，答案不唯一、會洩題、時效性強的刪掉，再抽樣查證；類別 `k` 見 i18n 的 `xk` |
| `tools/extra-sources.json` | 「更多知識」每條的來源網址（網頁不載入） |
| `data/taiwan-units-*.js`、`china-units-*.js`、`world-units-*.js` | 臺灣各縣市、中國各省、世界各國的知識卡，每一區直接寫中英日三份 |
| `js/i18n.js` | 介面文字（中英日） |
| `js/regions.js` | 地區清單，把地圖和知識卡組成一個地區，依語言給地名與卡片內容（日本與中國、世界兩種資料格式各有一套）；各洲分頁由世界的地圖與卡片切出來 |
| `js/store.js` | 存檔、熟練度、間隔複習、過了哪些關、統計／成就／配件／肉球幣／裝扮、兩份進度的合併 |
| `js/rewards.js` | 肉球幣規則、扭蛋、成就、套裝、旅程稱號 |
| `js/i18n-rewards.js` | 配件、成就、稱號、扭蛋的三語文字 |
| `js/sync.js` | 雲端存檔（CloudSave） |
| `js/quiz.js` | 出題：關卡的題組 |
| `js/map.js` | SVG 地圖：縮放、拖曳、點擊、標籤、小國圓點、Komugi；`static` 選項只能點不能平移縮放（首頁用） |
| `js/komugi.js` | Komugi（頭像與全身）與 134 件配件的圖案；頭部配件用頭的座標，其餘用全身座標 |
| `js/audio.js` | 音樂與音效 |
| `js/main.js` | 畫面與玩法流程、底色主題、設定 |
| `js/version.js` | 版號 |

沒有建置步驟，`index.html` 直接載入所有檔案。

## 重產地圖與圖示

```
npm install
node tools/build-map.mjs japan
node tools/build-map.mjs taiwan
node tools/build-map.mjs china
node tools/build-map.mjs world
powershell -File tools\build-icons.ps1 [-AndroidRes <KMapApp\app\src\main\res>]
```

- **地圖**：第一次會下載 Natural Earth 的原始檔到 `tools/.cache/`：日本、中國用 1:10m 省縣界（約 40MB），世界用 1:50m 國界（約 3MB）。臺灣用 taiwan-atlas（內政部縣市界的 TopoJSON），因為 Natural Earth 兩種比例尺都漏了連江縣（馬祖）。用 mapshaper 簡化並保留拓撲，再用 topojson 算相鄰關係。日本、臺灣、中國用等距圓柱投影，世界用 Equal Earth 等面積投影（中央經線 11°E）。哪些算國家、哪些併進別國或畫成底圖、資料不準的相鄰關係、跨海連結、插圖框、各洲取景框，都寫在 `build-map.mjs` 的設定裡
- **圖示**：用 Edge headless 截 `tools/icon.html`

版號只寫在 `js/version.js`：首頁標題旁顯示它，`sw.js` 也拿它當快取名稱。改了網頁就要加版號，舊快取才會被換掉。
