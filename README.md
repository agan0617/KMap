# K地圖

邊玩邊熟悉地圖的網頁遊戲。把每一塊地方從灰色點亮成全彩，集滿御朱印。

網頁版：<https://agan0617.github.io/KMap/>　Android 版：[KMapApp](https://github.com/agan0617/KMapApp)（WebView 外殼，網頁更新 App 就跟著更新）

## 地區

| 地區 | 單位 | 狀態 |
|---|---|---|
| 日本 | 47 都道府縣 | 可以玩 |
| 中國 | 省級行政區 | 製作中 |
| 世界 | 國家（歐洲是其中一洲） | 製作中 |

## 玩法

- **圖鑑**：點地圖上任一塊看知識卡，內容有縣廳所在地、舊國名、名產、名勝、小知識、方言。地名會依縮放程度顯示，塞得下字才出現
- **找位置**：「秋田縣在哪？」在地圖上點出來
- **知識找地點**：看名產、名勝、小知識或方言，猜是哪裡。提示裡的縣名會遮成○○
- **鄰接旅行**：陪 Komugi 從起點走到目的地，每一步只能走到相鄰的地方。虛線是橋、隧道或航線；步數等於最短路線拿三顆星
- **限時連擊**：60 秒內混合出題，每連對 5 題，每題多 1 分
- **今日挑戰**：每天一組固定的 10 題，只記第一次的成績，另計連續天數

### 熟練度

| 等級 | 條件 | 地圖顏色 |
|---|---|---|
| 未踏 | — | 灰 |
| 到訪 | 答對一次 | 淡 |
| 熟悉 | 第一次答對後隔 2 天以上又答對 | 中 |
| 制霸 | 熟悉，且「找位置」與「知識找地點」都答對過 | 全彩，蓋一個御朱印 |

出題會優先挑到期該複習的、常錯的、還沒碰過的地方（Leitner 間隔複習）。進度存在瀏覽器的 localStorage。

### 音樂與音效

全部用 Web Audio 即時合成，沒有音檔。日本的背景音樂用都節音階的撥弦聲，限時連擊時換成快板。設定裡可以分開關掉音樂和音效。

## 檔案

| 路徑 | 內容 |
|---|---|
| `data/<地區>-map.js` | 地圖的 SVG 路徑、相鄰關係、跨海連結、插圖框。由 `tools/build-map.mjs` 產生，不要手改 |
| `data/<地區>-info.js` | 知識卡（手寫） |
| `js/regions.js` | 地區清單，把地圖和知識卡組成一個地區 |
| `js/store.js` | 存檔、熟練度、間隔複習 |
| `js/quiz.js` | 出題、鄰接旅行的路線計算 |
| `js/map.js` | SVG 地圖：縮放、拖曳、點擊、標籤、Komugi |
| `js/audio.js` | 音樂與音效 |
| `js/main.js` | 畫面與玩法流程 |

沒有建置步驟，`index.html` 直接載入所有檔案。

## 重產地圖與圖示

```
npm install
node tools/build-map.mjs japan
powershell -File tools\build-icons.ps1 [-AndroidRes <KMapApp\app\src\main\res>]
```

- **地圖**：第一次會下載 Natural Earth 的 1:10m 行政區界（約 40MB）到 `tools/.cache/`。用 mapshaper 簡化並保留拓撲，再用 topojson 算相鄰關係。資料不準的相鄰關係、跨海連結、插圖框寫在 `build-map.mjs` 的 `REGIONS` 設定裡
- **圖示**：用 Edge headless 截 `tools/icon.html`

改了網頁要記得改 `sw.js` 的 `VERSION`，舊快取才會被換掉。

## 資料來源
