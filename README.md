# K地圖

邊玩邊熟悉地圖的網頁遊戲。把每一塊地方從灰色點亮成全彩，集滿印章。介面與知識卡有中文、英文、日文三種語言。

網頁版：<https://agan0617.github.io/KMap/>　Android 版：[KMapApp](https://github.com/agan0617/KMapApp)（WebView 外殼，網頁更新 App 就跟著更新）

## 地區

九個分頁，依序是臺灣、日本、中國，以及世界的六大洲（亞洲、歐洲、非洲、北美、南美、大洋洲），分頁放不下時可以左右滑。第一次打開預設臺灣。

- **六大洲共 197 國**：聯合國 193 個會員國，加上臺灣、梵蒂岡、科索沃、巴勒斯坦。港澳算在中國內。格陵蘭、西撒哈拉、各國海外屬地畫成灰色底圖，不能點
- **各洲分頁**：共用同一張世界地圖，只看那一洲的範圍，其他洲的國家畫成不能點的底圖；跨洲的連結（白令海峽等）在洲內不算相鄰。每一洲各有自己的今日挑戰、限時最佳與護照章冊；熟練度記在同一份世界進度裡，所以拆洲以前答過的都還在。成就照世界整體算（例如世界 50 章），門檻跟以前一樣。分區照聯合國地理分區，臺灣慣用叫法優先（伊朗放西亞、英國與愛爾蘭放西歐、德奧瑞放中歐），寫在 `data/world-continents.js`
- **選了分區**：出題、限時連擊、鄰接旅行只用那一區，地圖放大到那一區，區外變淡。今日挑戰不受影響，一律整個地區。圖鑑裡也有同一排分區按鈕，兩邊共用同一個設定
- **臺灣**：金門、馬祖放在左上的插圖框。卡片的「舊稱」欄放打狗、諸羅、竹塹這類舊地名；直轄市與市不列縣政府所在地
- **太小點不到的地方**（梵蒂岡、摩納哥、澳門…）會多畫一個固定大小的圓點

## 玩法

- **圖鑑**：點地圖上任一塊看知識卡，內容有首府、舊國名或簡稱、名產、名勝、小知識、方言。各洲的卡片附國旗。卡片底下有上一個／下一個（順序同紀念章冊，電腦可用左右方向鍵），不用關掉就能一路看下去；視窗大小固定、內容在中間捲，切換時按鈕位置不變。地名依縮放程度顯示，塞得下字才出現
- **找位置**：「秋田縣在哪？」在地圖上點出來
- **知識找地點**：看提示猜是哪裡，在地圖上點出來。一半題目用知識卡（名產、名勝、首府、小知識、方言；提示裡的地名會遮成○○，兩個地方寫成一樣的名產名勝不出題），另一半用地圖本身出：
  - **鄰居**：「和 A、B、C 都相鄰」，沒有別的地方也同時和它們相鄰才出
  - **方位**：「X 的東邊鄰居」，X 在那個方向只有一個鄰居才出（方向用兩地的中心點算，分八方位）
  - **剪影**：只給形狀，太小的地方不出
  - **國旗**：只有六大洲
  - **外語名**：用另一種語言的名稱找位置（中文介面出英文或日文名，以此類推；日文漢字跟中文只差新舊字體的不出）
  - **交通**：「從 A 經由〈青函隧道〉可以到哪裡？」，用地圖上的橋、隧道、航線出題
- **鄰接旅行**：陪 Komugi 從起點走到目的地，每一步只能走到相鄰的地方。虛線是橋、隧道或航線；步數等於最短路線拿三顆星
- **限時連擊**：60 秒內混合出題，每連對 5 題，每題多 1 分
- **今日挑戰**：每天一組固定的 10 題（整個地區，不受分區影響），只記第一次的成績，另計連續天數。每天第一次的獎勵最大（基本＋全對＋連續天數加成）；做完再玩就換一組新題（照複習優先度出），只給小額的再挑戰獎勵，成績與方格仍是第一次的。做完以後首頁的今日挑戰卡多一行今天的總進度：玩了幾組、答對幾題、賺了多少肉球幣、升級與蓋章幾個（各地區分開算，同步時同一天各欄取大的）。結算可以「分享成績」：產生一排 🟩🟥 方格加連續天數，手機叫出系統分享選單（可貼 LINE），沒有分享選單就複製到剪貼簿

出題類的模式答完一題後，面板分成兩欄，題目旁邊顯示答案解析：答案在哪一區、和誰相鄰；答錯時你點的地方在答案的哪個方向、兩地相鄰還是中間隔了幾個；知識題的提示原本屬於誰；找位置題附首府與小知識。點畫面任何地方（或「下一題」）進下一題；限時連擊不顯示解析、自動跳。

### 熟練度

| 等級 | 條件 | 地圖顏色 |
|---|---|---|
| 未踏 | — | 灰 |
| 到訪 | 答對一次 | 淡 |
| 熟悉 | 第一次答對後隔 2 天以上又答對 | 中 |
| 制霸 | 熟悉，且「找位置」與「知識找地點」都答對過 | 全彩，蓋一個章 |

出題會優先挑到期該複習的、常錯的、還沒碰過的地方（Leitner 間隔複習）。作答中的地圖不顯示熟練度顏色，只標當題的對錯；圖鑑和鄰接旅行才看得到顏色。進度存在瀏覽器的 localStorage，各地區分開記。

### Komugi 與獎勵

Komugi 是戴耳機的柴犬，旅行模式的旅人兼吉祥物。首頁由上而下是：

1. **Komugi 小屋**：全身的 Komugi、稱號、下一個獎勵的提示（優先提示目前地區的地區成就）、肉球幣、衣櫃、扭蛋和紀念章冊按鈕
2. **今日挑戰**卡片：沒玩寫獎勵起跳數，玩過寫今天的成績、連續天數與再挑戰提示
3. 地區分頁、分區、**地圖**：不能平移縮放（頁面下滑才不會誤觸），點一塊直接看知識卡；左上角顯示解鎖百分比（到訪以上的地方佔比），右上角是圖鑑按鈕；到訪過的地方標上地名（塞得下才顯示）
4. 熟練度進度條與四個模式（找位置、知識找地點、鄰接旅行、限時連擊）

- **配件**：134 件，分 10 個部位（頭、眼睛、臉、脖子、衣服、背後、手上、腳、夥伴、背景），稀有度 N／R／SR／SSR。同一部位穿一件；拿到新配件時那個部位空著就自動穿上。首頁、衣櫃是全身，標題列、通知、鄰接旅行裡是頭像（頭像戴得上頭、眼睛、臉、脖子四個部位）。「夥伴」是坐在 Komugi 旁邊的小動物
- **肉球幣 🐾**：答對 +2、連擊 5 以上每題再 +1、到訪 +3、熟悉 +5、蓋章 +15、鄰接旅行每顆星 +5、今日挑戰每天第一次 +30（全對再 +30，連續天數每天再 +5、最多 +50）、再挑戰 +5（全對再 +5，每次都給）、成就 +30
- **扭蛋**：30 幣一次，從 102 件「扭蛋池」抽，機率 N 55%・R 30%・SR 12%・SSR 3%；每台裝置每 10 抽保底一件 SR 以上；抽到重複的退 10 幣。夠扭兩次以上會多一顆「全部扭」：把肉球幣扭到不夠為止（重複退回的幣夠也接著扭），一次列出拿到的所有配件。小屋的扭蛋按鈕平常跟衣櫃、紀念章冊同色，夠扭時才變紅並標出能扭幾次
- **成就**：32 個，各送一件指定配件。其中 16 個是地區成就：臺灣、日本、中國、世界各四階（例如臺灣 5 章送藍白拖、18 章送臺灣黑熊夥伴、日本 20 章送浴衣、35 章送武士頭盔、各地區全制霸送該地區的背景），要拿就得把那個地區學熟
- **套裝與稱號**：25 套（臺灣之旅、日本祭典、太空任務、魔法師、海盜船、忍者、逛夜市、熊貓之家…），集滿可以一鍵穿上整套、設成首頁的稱號
- **衣櫃**：上面是全身預覽，下面依部位分頁，最後一頁是套裝；沒拿到的配件顯示來源（哪個成就、進度幾分之幾，或扭蛋）。視窗固定高度，切分頁不會跳

成就、配件、套裝定義在 `js/rewards.js`，配件圖案在 `js/komugi.js`，名稱與說明在 `js/i18n-rewards.js`。

### 雲端存檔

設定裡可以連上 CloudSave（私有 repo），進度會同步到 `saves/kmap.json`，手機、電腦、App 共用：

- **token**：存在各裝置，瀏覽器直接呼叫 GitHub API，沒有中間伺服器。要能讀寫 CloudSave 的 Contents
- **沿用連線**：K地圖跟 K書吧、魔塔在同一個網域，這台瀏覽器連過它們就直接沿用那組 token。App 的 WebView 資料分開，要在 App 裡另外貼一次
- **合併**：熟練度、答對次數取高的；複習排程用最近玩的那一份；最佳分數、統計取高的；成就與配件聯集；肉球幣與扭蛋次數每台裝置各記收支、合併時各裝置取大的再加總；Komugi 的裝扮與稱號用最近換的那一份；今日挑戰同一天兩邊都有就留本機的。多台裝置同時玩不會互相蓋掉
- **同步時機**：打開時、切回畫面時拉一次；答題後 3 秒推上去；切走畫面前把還沒推的推上去
- **不同步的**：語言、音樂、音效、底色這類設定，各裝置自己記

### 語言

首頁右上角切換中文（繁體）、英文、日文，介面和知識卡都會換，選擇記在瀏覽器裡。第一次打開時依瀏覽器語言決定。名字下面的小字：

| 地區 | 中文 | 英文 | 日文 |
|---|---|---|---|
| 臺灣 | 官方英文名 | 中文 | 日文常用讀音 |
| 日本 | 假名讀音 | 日文漢字 | 假名讀音 |
| 中國 | 漢語拼音 | 中文 | 假名讀音 |
| 世界 | 英文國名 | 當地語言的國名 | 英文國名 |

### 音樂與音效

全部用 Web Audio 即時合成，沒有音檔。背景音樂依地區換音階：日本是都節音階的撥弦聲、臺灣是羽調五聲音階、中國是宮調五聲音階、六大洲是大調；限時連擊時換成快板。設定裡可以分開關掉音樂和音效。

### 底色

設定裡可以換整個 App 的底色（同 K書吧）：米（預設）、白、綠、夜，或「系統」跟著裝置的深色模式在米與夜之間切。地圖的熟練度顏色會從該底色的陸地色往分區色混，所以每種底色都看得出深淺。

## 檔案

| 路徑 | 內容 |
|---|---|
| `data/<地區>-map.js` | 地圖的 SVG 路徑、相鄰關係、跨海連結、插圖框、底圖、各洲取景框。由 `tools/build-map.mjs` 產生，不要手改 |
| `data/japan-info.js` | 日本知識卡的中文底稿 |
| `data/japan-info.en.js`、`.ja.js` | 日本知識卡的英文、日文翻譯，陣列與底稿逐項對應；缺的欄位顯示中文 |
| `data/taiwan-info.js`、`china-info.js`、`world-info.js` | 臺灣、中國、世界的分區、欄位名稱、印章樣式 |
| `data/world-continents.js` | 六大洲分頁：每一洲底下的地理分區與各分區的國家 |
| `data/taiwan-units-*.js`、`china-units-*.js`、`world-units-*.js` | 臺灣各縣市、中國各省、世界各國的知識卡，每一區直接寫中英日三份 |
| `js/i18n.js` | 介面文字（中英日） |
| `js/regions.js` | 地區清單，把地圖和知識卡組成一個地區，依語言給地名與卡片內容（日本與中國、世界兩種資料格式各有一套）；各洲分頁由世界的地圖與卡片切出來 |
| `js/store.js` | 存檔、熟練度、間隔複習、統計／成就／配件／肉球幣／裝扮、兩份進度的合併 |
| `js/rewards.js` | 肉球幣規則、扭蛋、成就、套裝 |
| `js/i18n-rewards.js` | 配件、成就、套裝、扭蛋的三語文字 |
| `js/sync.js` | 雲端存檔（CloudSave） |
| `js/quiz.js` | 出題、鄰接旅行的路線計算 |
| `js/map.js` | SVG 地圖：縮放、拖曳、點擊、標籤、小國圓點、Komugi；`static` 選項只能點不能平移縮放（首頁用） |
| `js/komugi.js` | Komugi（頭像與全身）與 134 件配件的圖案；頭部配件用頭的座標，其餘用全身座標 |
| `js/audio.js` | 音樂與音效 |
| `js/main.js` | 畫面與玩法流程、底色主題、設定 |
| `js/version.js` | 版號 |

沒有建置步驟，`index.html` 直接載入所有檔案。

## 重產地圖與圖示

```
npm install
node tools/build-map.mjs japan
node tools/build-map.mjs taiwan
node tools/build-map.mjs china
node tools/build-map.mjs world
powershell -File tools\build-icons.ps1 [-AndroidRes <KMapApp\app\src\main\res>]
```

- **地圖**：第一次會下載 Natural Earth 的原始檔到 `tools/.cache/`：日本、中國用 1:10m 省縣界（約 40MB），世界用 1:50m 國界（約 3MB）。臺灣用 taiwan-atlas（內政部縣市界的 TopoJSON），因為 Natural Earth 兩種比例尺都漏了連江縣（馬祖）。用 mapshaper 簡化並保留拓撲，再用 topojson 算相鄰關係。日本、臺灣、中國用等距圓柱投影，世界用 Equal Earth 等面積投影（中央經線 11°E）。哪些算國家、哪些併進別國或畫成底圖、資料不準的相鄰關係、跨海連結、插圖框、各洲取景框，都寫在 `build-map.mjs` 的設定裡
- **圖示**：用 Edge headless 截 `tools/icon.html`

版號只寫在 `js/version.js`：首頁標題旁顯示它，`sw.js` 也拿它當快取名稱。改了網頁就要加版號，舊快取才會被換掉。

## 資料來源

- 地圖：[Natural Earth](https://www.naturalearthdata.com/)，公有領域；臺灣縣市界：內政部國土測繪中心（政府資料開放授權），經 [taiwan-atlas](https://github.com/dkaoster/taiwan-atlas) 轉成 TopoJSON
- 知識卡：依維基百科整理，每張卡附連結（日本依日文維基；中文、英文介面分別連到該語言的維基）
